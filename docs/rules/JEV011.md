# JEV011 description-repeats-name

An option's description only repeats its name, or a Noul's criteria say yes and no. Jev matches the state against the description, and this one says nothing.

On by default, as `warning`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "choice",
      "instructions": "Which team should handle this?",
      "criteria": {
        "billing": "Billing",
        "technical": "Technical",
        "other": "Other"
      }
    }
  }
}
```

> The description of 'billing' only repeats its name. Jev matches the state against the description, so say what belongs under this option.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "choice",
      "instructions": "Which team should handle this?",
      "criteria": {
        "billing": "Charges, invoices and payment problems",
        "technical": "Faults, errors and outages",
        "other": "Fits none of the other options"
      }
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV011
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV011:your-question-id"] }
```
