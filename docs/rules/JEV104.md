# JEV104 compound

A Noul joins two judgments with 'and'.

Off by default. Turn it on in `jevlint-le.json` with `{ "rules": { "JEV104": "warning" } }`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Is the customer angry and asking for a refund?"
    }
  }
}
```

> This question joins two judgments with 'and'. An input that is one and not the other cannot be answered. Ask each as its own question and combine the answers in code.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "a": {
      "type": "noul",
      "instructions": "Is the customer angry?"
    },
    "b": {
      "type": "noul",
      "instructions": "Is the customer asking for a refund?"
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV104
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV104:your-question-id"] }
```
