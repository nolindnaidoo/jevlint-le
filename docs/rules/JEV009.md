# JEV009 too-few-options

A Choice with one option or a Score with one level gives every input the same answer.

On by default, as `info`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "team": { "type": "choice", "instructions": "Which team should handle this?", "criteria": { "billing": "Charges and refunds" } }
  }
}
```

> This Choice has 1 option, so every input gets the same answer.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "team": { "type": "choice", "instructions": "Which team should handle this?", "criteria": { "billing": "Charges and refunds", "delivery": "Late or damaged parcels", "other": "Fits neither" } }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV009
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV009:your-question-id"] }
```
