# JEV002 choice-option-limit

A Choice has more than 255 options. The API rejects it.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Example

It takes 256 options to trigger, which is too long to show here.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV002
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV002:your-question-id"] }
```
