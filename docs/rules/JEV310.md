# JEV310 jev-overlapping-questions

Jev reads two questions in one request as asking for the same judgment.

On by default, as `info`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

This one is asked about a whole request, not one question: every pair of questions, or the state written in the file.

It is reported when Jev puts the probability of yes at 0.15 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV310
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV310:your-question-id"] }
```
