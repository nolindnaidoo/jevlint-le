# JEV307 jev-ordered-options

Jev reads a Choice's options as steps on one scale, which a Score would place between.

On by default, as `info`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

> Are the options in `question.criteria` steps on a single scale, running from less of something to more of it?

It is reported when Jev puts the probability of yes at 0.8 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV307
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV307:your-question-id"] }
```
