# JEV301 jev-counting

Jev reads the question as needing counting or arithmetic.

On by default, as `warning`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

> Does answering `question.instructions` need items to be counted, numbers to be compared, or arithmetic to be done?

It is reported when Jev puts the probability of yes at 0.96 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV301
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV301:your-question-id"] }
```
