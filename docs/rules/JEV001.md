# JEV001 unpinned-model

`jev-latest` and `jev-preview` move with each release, so answers can change with no change on your side.

On by default, as `warning`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-latest",
  "questions": {
    "late": { "type": "noul", "instructions": "Did the parcel arrive after the promised day?" }
  }
}
```

> 'jev-latest' is an alias that moves to each new release, so answers can change with no change on your side. Pin the versioned id from a response's 'model' field once your thresholds are tuned.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "late": { "type": "noul", "instructions": "Did the parcel arrive after the promised day?" }
  }
}
```

## Fixing it

A quick fix is offered on the lightbulb: Pin to 'jev-1.13.0', the version current on 2026-10-04. It is never applied by `--fix` or on save, because it changes what a working request does.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV001
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV001:your-question-id"] }
```
