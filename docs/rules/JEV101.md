# JEV101 double-negative

A question negates twice in one clause, or a negation sits directly on another.

On by default, as `info`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Is it not the case that the order has not shipped?"
    }
  }
}
```

> This question negates twice. Jev answers doubly negated questions less reliably. Ask for the positive case directly.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Has the order shipped?"
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV101
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV101:your-question-id"] }
```
