# JEV304 jev-overlapping-levels

Jev reads two levels of a Score as the same situation.

On by default, as `warning`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

> Do two of the levels in `question.criteria` describe the same situation in different words?

It is reported when Jev puts the probability of yes at 0.6 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV304
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV304:your-question-id"] }
```
