# JEV109 multi-dimension-level

A Score level lists three or more qualities.

Off by default. Turn it on in `jevlint-le.json` with `{ "rules": { "JEV109": "warning" } }`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "quality": { "type": "score", "instructions": "How good is the reply?", "criteria": ["Rude, slow and wrong", "Polite, slow and partly right", "Polite, fast and right"] }
  }
}
```

> This level lists several qualities at once. An input high on one and low on another cannot be placed. Use one Score per quality.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "accuracy": { "type": "score", "instructions": "How accurate is the reply?", "criteria": ["States something false", "Correct but leaves out part of the answer", "Correct and complete"] }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV109
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV109:your-question-id"] }
```
