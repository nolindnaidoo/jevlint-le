# JEV110 degree-levels

Score levels are degree words, or one word turned up and down.

Off by default. Turn it on in `jevlint-le.json` with `{ "rules": { "JEV110": "warning" } }`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "score",
      "instructions": "How severe is this bug report?",
      "criteria": [
        "Low",
        "Medium",
        "High"
      ]
    }
  }
}
```

> These Score levels name degrees, not situations. Jev matches the state against each description, so describe what each level looks like.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "score",
      "instructions": "How severe is this bug report?",
      "criteria": [
        "Cosmetic, and nobody is blocked",
        "Broken or degraded, but a workaround exists",
        "No workaround, and work has stopped"
      ]
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV110
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV110:your-question-id"] }
```
