# JEV005 duplicate

A question id, option or level appears twice. In an object the later one silently replaces the earlier.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "team": { "type": "noul", "instructions": "Is this for the billing team?" },
    "team": { "type": "noul", "instructions": "Is this for the delivery team?" }
  }
}
```

> Question id 'team' appears twice. The later one silently replaces the earlier.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "billing": { "type": "noul", "instructions": "Is this for the billing team?" },
    "delivery": { "type": "noul", "instructions": "Is this for the delivery team?" }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV005
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV005:your-question-id"] }
```
