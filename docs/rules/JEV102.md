# JEV102 arithmetic

The question asks Jev to count or compare numbers.

On by default, as `warning`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Are more than three of the items in `items` the name of a fruit?"
    }
  }
}
```

> This question asks Jev to count or compare numbers, which it does not do reliably. Ask one question per item and do the arithmetic in code.

## Not flagged

```json
{
  "model": "jev-1.13.0"
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV102
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV102:your-question-id"] }
```
