# JEV010 unused-disable

A `jevlint-le-disable` comment silences nothing, so it can only hide a finding added later.

On by default, as `warning`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```js
// jevlint-le-disable-next-line JEV004
const late = { type: 'noul', instructions: 'Did the parcel arrive after the promised day?' };
```

> This comment silences nothing. Remove it, so it cannot hide a finding that is added later.

## Not flagged

```js
const late = { type: 'noul', instructions: 'Did the parcel arrive after the promised day?' };
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

Remove the comment it points at. To stop the rule itself, set it to `off` in `jevlint-le.json`.

## Source

This rule is about the linter's own comments, so it has no vendor page.
