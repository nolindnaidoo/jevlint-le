# JEV105 generation

The question asks for a value or for text to be written.

On by default, as `warning`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "summary": { "type": "noul", "instructions": "Write a one-line summary of the complaint." }
  }
}
```

> This asks for a value or for text. Jev only picks among answers you give it. Offer the candidates as a Choice, or use a generative model.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "refund": { "type": "noul", "instructions": "Does the customer ask for a refund?" }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV105
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV105:your-question-id"] }
```
