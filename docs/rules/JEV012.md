# JEV012 terse-instructions

The instructions are one or two words, so the question leans on its id. Jev is sent the instructions and never the id.

On by default, as `warning`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Refund?"
    }
  }
}
```

> The instructions are one word, so the question leans on its id for its meaning. Jev reads only the instructions. Write out what is being asked.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Does the customer ask for their money back?"
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV012
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV012:your-question-id"] }
```
