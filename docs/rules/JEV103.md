# JEV103 date-comparison

The question asks Jev to order two times or measure the gap between them.

On by default, as `info`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "early": { "type": "noul", "instructions": "Was the order placed before the sale started?" }
  }
}
```

> This question asks Jev to order or measure dates, which it reads as text and not as quantities. Have it extract the parts of each date and compare them in code.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "sale": { "type": "noul", "instructions": "Does the order mention a sale price?" }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV103
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV103:your-question-id"] }
```
