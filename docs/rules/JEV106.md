# JEV106 multi-hop

One sentence chains three or more relationships.

Off by default. Turn it on in `jevlint-le.json` with `{ "rules": { "JEV106": "warning" } }`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "manager": { "type": "noul", "instructions": "Is the manager of the driver of the van that carried the parcel named in the message?" }
  }
}
```

> This question chains several relationships before it reaches the thing it asks about. Each hop costs accuracy. Resolve the chain in code and ask about the result.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "manager": { "type": "noul", "instructions": "Does the message name a manager?" }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV106
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV106:your-question-id"] }
```
