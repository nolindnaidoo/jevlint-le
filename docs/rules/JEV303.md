# JEV303 jev-overlapping-options

Jev reads two options of a Choice as covering the same cases.

On by default, as `info`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

> Could a single input reasonably fit two of the options in `question.criteria` at the same time? Do not count a catch-all option such as other or none.

It is reported when Jev puts the probability of yes at 0.75 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV303
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV303:your-question-id"] }
```
