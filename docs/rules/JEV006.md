# JEV006 criteria-shape

A Choice needs a map of options, a Score needs an array of levels, and a Noul takes `true` and `false`.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "late": { "type": "noul", "instructions": "Did the parcel arrive after the promised day?", "criteria": { "yes": "It arrived after the promised day", "no": "It arrived on or before it" } }
  }
}
```

> Noul criteria take 'true' and 'false'. 'yes' is not a documented key.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "late": { "type": "noul", "instructions": "Did the parcel arrive after the promised day?", "criteria": { "true": "It arrived after the promised day", "false": "It arrived on or before it" } }
  }
}
```

## Fixing it

`--fix` and fix on save mend this: Rename 'yes' to 'true'.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV006
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV006:your-question-id"] }
```
