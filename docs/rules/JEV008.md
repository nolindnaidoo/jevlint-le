# JEV008 numeric-levels

Score levels are bare numbers. Jev matches the state against each description and never sees its position.

On by default, as `warning`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "score",
      "instructions": "How severe is this bug report?",
      "criteria": [
        "0",
        "1",
        "2"
      ]
    }
  }
}
```

> These Score levels are bare numbers. Jev matches the state against each level description and never sees its position, so a number gives it nothing to match. Describe the situation each level stands for.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "score",
      "instructions": "How severe is this bug report?",
      "criteria": [
        "Cosmetic, and nobody is blocked",
        "Broken or degraded, but a workaround exists",
        "No workaround, and work has stopped"
      ]
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV008
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV008:your-question-id"] }
```
