# JEV000 unreadable

Part of the question is built at runtime, so the rules that need it did not run.

On by default, as `hint`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```js
const request = {
  questions: {
    late: { type: 'noul', instructions: buildQuestion(order) },
  },
};
```

> Cannot fully read the instructions of this question: part of it is built at runtime. The rules that need it did not run.

## Not flagged

```js
const request = {
  questions: {
    late: { type: 'noul', instructions: 'Did the parcel arrive after the promised day?' },
  },
};
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV000
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV000:your-question-id"] }
```
