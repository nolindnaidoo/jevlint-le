# JEV111 numeric-encoding

The question refers to a value by hex or RGB encoding.

Off by default. Turn it on in `jevlint-le.json` with `{ "rules": { "JEV111": "warning" } }`. A wording rule. It matches patterns in English text, so it can miss a defect or flag a question that is fine.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "brand": { "type": "noul", "instructions": "Is the button colour #FF6600?" }
  }
}
```

> This question refers to a value by its hex or RGB encoding. Jev judges named values better than encoded ones. Convert it in code and pass the name.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "brand": { "type": "noul", "instructions": "Is the button orange?" }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV111
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV111:your-question-id"] }
```
