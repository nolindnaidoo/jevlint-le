# JEV007 invalid-question

The type is missing or unknown, or the instructions are an empty string.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "refund": { "type": "noul", "instructions": "Does the customer ask for a refund?" },
    "late": { "type": "nuol", "instructions": "Did the parcel arrive after the promised day?" }
  }
}
```

> Question type "nuol" does not exist. The types are noul, choice and score.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "refund": { "type": "noul", "instructions": "Does the customer ask for a refund?" },
    "late": { "type": "noul", "instructions": "Did the parcel arrive after the promised day?" }
  }
}
```

## Fixing it

`--fix` and fix on save mend this: Change to 'noul'.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV007
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV007:your-question-id"] }
```
