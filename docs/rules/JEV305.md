# JEV305 jev-label-mismatch

Jev reads an option as named for one thing and described as another.

On by default, as `warning`. Asks Jev. It runs only under **Check This File with Jev** in the editor or `--jev` on the command line, with your key, and never while linting.

## What Jev is asked

> In `question.criteria`, does any option have a name that says one thing while its description says another?

It is reported when Jev puts the probability of yes at 0.7 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV305
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV305:your-question-id"] }
```
