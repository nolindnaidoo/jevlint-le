# JEV003 score-level-limit

A Score has more than 10 levels. The API rejects it.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "urgency": { "type": "score", "instructions": "How urgent is the request?", "criteria": ["Level 0 of urgency: none", "Level 1 of urgency: trivial", "Level 2 of urgency: minor", "Level 3 of urgency: low", "Level 4 of urgency: modest", "Level 5 of urgency: medium", "Level 6 of urgency: raised", "Level 7 of urgency: high", "Level 8 of urgency: severe", "Level 9 of urgency: critical", "Level 10 of urgency: emergency"] }
  }
}
```

> This Score has 11 levels. The API accepts at most 10.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "urgency": { "type": "score", "instructions": "How urgent is the request?", "criteria": ["Can wait a week or more", "Needed within a few days", "Needed today"] }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV003
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV003:your-question-id"] }
```
